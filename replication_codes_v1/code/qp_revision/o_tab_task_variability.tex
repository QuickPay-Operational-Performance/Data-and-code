\begin{itemize}
\tightlist
\item
  \(Treat_i=1\) for contractors that hold at least one small project
  over the sample horizon.
\item
  \(Treat_i=0\) for contractors that hold only large projects.
\item
  For treated group, focus only on new projects/budget/etc. acquired for
  small projects.
\item
  For the control group, by construction, changes will account for new
  projects/tasks/budget acquired for large projects
\end{itemize}
